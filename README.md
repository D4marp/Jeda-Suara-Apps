Jurnal harian offline (Flutter, Riverpod, SharedPreferences, Clean Architecture). Lihat PRD v1.0.

```bash
flutter pub get
flutter run
flutter test
```

Fitur: tulis/baca/hapus/edit catatan, Mock AI Mood Scanner, sematkan, pencarian, filter mood,
draft otomatis, statistik (streak, mood, 7 hari), tema terang/gelap, ganti PIN,
kunci 30 detik setelah 5 kali PIN salah, hapus semua catatan.
